yogoan は、IT用語を文章と図で解説する用語集です。
「なんとなく聞いたことはあるけれど、説明はできない」という言葉を、短く・正確に理解できることを目指しています。

## 使い方

- **カテゴリから探す** — 左のサイドバーから、分野ごとに用語を一覧できます。
- **キーワードで探す** — 画面上部の検索ボックスから、用語名や本文を全文検索できます。
- **新しく追加された用語を見る** — トップページの「最近の記事」に、新しく追加された用語が並びます。

## 記事の構成

各記事は、おおむね次の流れで書かれています。

1. **ひとことで** — まず結論を一文で。ここだけ読めば大枠がつかめます。
2. **詳しく** — 仕組みや役割を、見出しごとに分けて解説します。
3. **図・比較** — 似た用語との違いや、処理の流れを図や表で整理します。

## カテゴリ

### Web・フロントエンド

ブラウザで動く部分にかかわる用語です。HTML / CSS / JavaScript、フレームワーク、レンダリング方式、ブラウザの仕組みなどを扱います。

### API・バックエンド

サーバー側の処理にかかわる用語です。API の設計、認証・セッション、データベース、サーバーサイドのフレームワークなどを扱います。

### クラウド・インフラ

アプリケーションを動かす土台にかかわる用語です。クラウドサービス、コンテナ、CI/CD、デプロイ、監視などを扱います。

### AI

人工知能にかかわる用語です。機械学習の基本概念から、大規模言語モデル（LLM）、プロンプト、AI を組み込んだ開発手法までを扱います。

### 設計・手法

ソフトウェアの作り方・進め方にかかわる用語です。設計原則、アーキテクチャ、デザインパターン、テスト、開発プロセスなどを扱います。

### ネットワーク

コンピューター同士の通信にかかわる用語です。HTTP、DNS、TCP/IP、プロキシ、CDN などを扱います。

### セキュリティ

システムやデータを守るための用語です。暗号化、認証・認可、代表的な攻撃手法とその対策などを扱います。

### その他

上記のどれにも当てはまらない用語や、分野をまたぐ一般的な用語を扱います。
